PRMT1 Allosteric Regulation - MD Simulation Data

This repository contains the computational data and input files for our study on PRMT1 allosteric regulation.

Repository Structure

1. cosolvent_MD/
Cosolvent molecular dynamics simulations of PRMT1 with five probe molecules (IPH, IMD, 5MT, 2AP, CHX), each with three independent replicates (500 ns each). For each system, topology files, input parameters, and analysis results are provided.

2. virtual_screening_MD(MZP-13)/
400 ns MD simulation of the hit compound MZP-13 binding to PRMT1, including topology files, input parameters, trajectory analysis data, and MMPBSA binding free energy results.

Notes
Full-length trajectories are not included due to file size limitations but are available upon reasonable request from the corresponding author.
